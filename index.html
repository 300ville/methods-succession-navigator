Background

The Method Succession Navigator identifies general accounting method consequences based on the party and transaction structure selected.

The tool addresses stock and asset transactions, Section 338(h)(10) elections, Section 351 transfers, Section 381 transactions, and consolidated group entries and exits.

This is a screening tool. Confirm the transaction documents, accounting method history, elections, procedural requirements, and current authority before using any result.

Developed by Jaime Garcia de Paredes and Briauna Williams-Henderson.

How to use

  1. Select the party or entity whose accounting method consequence you are analyzing.
  2. Select the transaction structure and any applicable election or consolidated group change.
  3. Review the method result, tax effect, governing rule, and follow-up items.
  4. Use the summary table to compare the general results for other transaction structures.
